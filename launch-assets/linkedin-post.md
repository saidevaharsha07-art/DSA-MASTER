DSA Magna isn't just another problem repository. It is a full-spectrum cognitive learning operating system designed around how humans actually master complex problem solving:

1. **The 4,000+ Unified Curriculum**: Structured into 7 progressive Mastery Bands across 13 Kingdom domains (Arrays, Trees, Graphs, Dynamic Programming, and beyond).
2. **Cognitive Metacognition (Thinking & Reflection Phases)**:
   - Before writing a single line of code, the system guides you to deconstruct constraints, write edge cases, and commit to time/space bounds.
   - After solving, it prompts deliberate reflection to imprint reusable mental models.
3. **Real-Time Interactive Visualizer**: Watch pointers shift, trees balance, and recursion trees unfold step-by-step with 7 dedicated algorithmic visualizers.
4. **Spaced Repetition Memory Command Center**: Built on the SM-2 algorithm to counteract the Ebbinghaus forgetting curve. It schedules targeted revisions before knowledge decays.
5. **AI Mentor Coaching Center**: Context-aware guidance powered by Google Gemini, offering hint ladders without spoiling the solution.
6. **Mock Interview Simulator**: Realistic timed behavioral and technical rounds with synthesized audio questions and comprehensive competency scorecards.
7. **Offline-First Resilience**: Zero account friction. Start practicing instantly in your browser with zero latency; sync seamlessly with Supabase cloud backup when ready.

Built with Next.js 15, TypeScript, Tailwind CSS, Monaco Editor, Supabase, and Google Gemini API.
